# AWS_DATA_ANALYSIS

ブラジルのECサイト「Olist」の公開データを使い、AWSとPythonでデータ分析に取り組むポートフォリオです。データの準備から可視化、統計的な確認、機械学習による予測まで、分析の過程と判断を記録しています。

> **現在の進捗:** 低評価予測モデルの評価方法を学習中です。分析結果やモデル評価は検証を進めながら更新します。

## プロジェクトの目的

- 注文価格や送料、配送状況とレビュー評価の関係を調べる
- 配送遅延日数とレビュー評価の関係を分析する
- レビュー1～2点を「低評価」と定義し、ロジスティック回帰で予測する
- 指標の意味や限界を確認し、分析上の判断を説明できる形で残す

## データ

- **データセット:** Brazilian E-Commerce Public Dataset by Olist
- **提供元:** [Kaggle – Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- **内容:** 注文、商品、販売者、顧客、配送、レビューなどに関するデータ
- **利用方法:** AWS S3に配置したデータをAmazon Athenaでクエリし、Pythonで分析

データセットの利用条件を確認し、元データをこのリポジトリには含めません。データの再配布は行わず、利用条件に従ってください。

## 分析内容

### 1. 注文価格・送料とレビュー評価

注文金額・送料とレビュー評価の関係を確認しています。

### 2. 配送遅延とレビュー評価

実配送日と予定配送日から、次のように配送遅延日数を定義しました。

```text
delivery_delay_days = 実配送日 - 予定配送日
```

負の値は予定より早い配送、0は予定どおり、正の値は予定より遅い配送を表します。レビュー評価ごとの分布を確認し、Kruskal–Wallis検定とDunn検定（Bonferroni補正）を用いて群間差を調べました。

### 3. 低評価予測

- **目的変数:** レビュー1～2点を低評価（`low_review = 1`）とする二値分類
- **説明変数:** 注文金額、送料、配送遅延日数
- **モデル:** ロジスティック回帰
- **確認項目:** オッズ比、予測確率、混同行列、Accuracy、Precision、Recall、F1-score、ROC-AUC、ROC曲線、Precision–Recall曲線

低評価は全体の約12.77%で、クラスに偏りがあります。そのためAccuracyだけで判断せず、PrecisionやRecallなども確認しています。

## 現時点の学習メモ

初期の学習では、Train/Testの2分割でしきい値を変えたときの指標を確認しました。試したしきい値の範囲では、低いしきい値でRecallが上がる一方、Precisionとのバランスが変わることを確認しています。また、初期モデルのROC-AUCは0.6744でした。

これらは手法を学ぶための途中結果です。初期のしきい値比較ではTestデータも参照していたため、最終的な性能としては扱いません。今後はTrain / Validation / Testに分割し、Validationでしきい値を決めたうえで、Testで最終評価する予定です。
